# EMG Pathway｜肌電路徑選肌

復健科醫師用的離線 needle EMG 臨床工作台。依神經根、神經叢或周邊神經選擇最小化肌肉組合，顯示完整神經路徑、鑑別肌肉、條件式追加建議，以及中英並列的定位與進針資訊。

## 功能

- 上下肢神經路徑互動與雙向高亮
- 根病變、神經叢、單一周邊神經與常見全身性模式
- 必查／鑑別用／視結果追加的動態 protocol
- 檢查結果驅動的下一塊肌肉建議
- 可搜尋的肌肉資料庫與進針安全提示
- 鑑別比較、列印、離線 PWA
- 不儲存病人識別資料

## 本機開發

```bash
pnpm install
pnpm dev
```

## 驗證

```bash
pnpm test
pnpm build
pnpm lint
```

## 重要限制

本工具供受過訓練的醫師作為決策支援與教學參考，不取代病史、理學檢查、完整電生理評估、個別風險判斷或在地規範。進針位置、方向與針長均須依體型、解剖變異及超音波所見調整。
